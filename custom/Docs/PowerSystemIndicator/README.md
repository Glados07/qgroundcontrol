# PowerSystemIndicator 用户说明

PowerSystemIndicator 将电池状态和燃料电池控制器（FCS）集中到 QGroundControl 顶部工具栏的同一个入口中。用户可以从顶部快速查看电压和功率，点击后在同一页面查看电池详情、低电量保护参数、FCS 状态并执行 FCS 操作。

开发和测试资料分别见 [DEVELOP.md](DEVELOP.md) 与 [TEST.md](TEST.md)。

## 1. 使用前提

- QGroundControl 已连接活动飞控，且当前车辆不是离线编辑车辆。
- 飞控和 QGroundControl 使用匹配的 FuelCellController MAVLink 定义。
- 修改低电量参数或操作真实 FCS 前，应确认台架、供电、负载和设备状态满足现场安全要求。
- 展开页采用固定左右双栏，需要正常工作窗口具有足够宽度；不提供窄屏标签或压缩布局。

没有活动车辆时，PowerSystemIndicator 不显示。

## 2. 顶部工具栏

顶部入口包含 FCS 图形以及两行电池测量值：

- 第一行：当前活动车辆第一个电池条目的电压，单位为 V；
- 第二行：由同一电池电压和电流计算的功率，单位为 W；
- 数据不可用时显示 `— V` 或 `— W`。

主图标颜色表示电池状态：

| 颜色 | 含义 |
| --- | --- |
| 绿色 | 正常 |
| 黄色 | 低电量 |
| 橙色 | 严重低电量 |
| 红色 | 紧急、失效或不健康 |
| 默认文字色 | 状态未知、正在充电或没有足够数据 |

FCS 状态不会改变主图标的电池颜色。新鲜遥测确认 FCS 已断连、处于故障关机或急停状态时，图标右上角显示红色角标；状态为输出电流受限时显示橙色角标。

## 3. 打开详情页

点击顶部 PowerSystemIndicator 后，详情页始终按左右双栏显示：

- 左侧：电池状态、低电量保护配置和锂电池 SOC；
- 右侧：燃料电池状态、盒子直发的测量值、飞控请求功率和控制按钮；
- 中间分隔线用于区分两个区域。

切换活动车辆时，当前详情页会自动关闭，以避免旧车辆的参数编辑状态被用于新车辆。

## 4. 左侧：电池和低电量保护

### 电池状态

`Power Status` 区域显示：

- Power State：电池状态；
- Measured Voltage：实测电压；
- Power：电压与电流计算得到的功率；
- Current：实测电流；
- Consumed：已消耗电量。

某个字段无效时只影响该字段，不会阻止 FCS 区域显示。

### 低电量保护配置

`Low Power Failsafe` 区域包含：

| 界面项 | 飞控参数 | 用途 |
| --- | --- | --- |
| Vehicle Action | `COM_LOW_BAT_ACT` | 低电量时的飞行动作 |
| Low Voltage | `UAVCAN_POW_LOW` | 低电量阈值 |
| Critical Voltage | `UAVCAN_POW_CRITI` | 严重低电量阈值 |
| Emergency Voltage | `UAVCAN_POW_EMERG` | 紧急电量阈值 |

参数尚未下载完成时显示等待提示；参数缺失时显示配置不可用。参数使用 QGroundControl 标准 Fact 控件逐项提交，仍受参数自身范围校验和重启要求约束。

修改前应记录原值，确认参数适用于当前机型，并在测试结束后恢复。界面不提供跨参数的统一保存或原子提交。

## 5. 右侧：燃料电池

### 状态信息

右侧按以下分组显示。FCS 返回的锂电池 SOC 显示在左栏底部。

- **燃料电池**：Device connection（设备连接状态）、FCS system status（FCS 实际执行状态）、DCDC output current（FCS 返回的 DCDC 输出电流）；
- **FCS 控制**：Requested power（飞控当前用于 CAN 下发的请求功率）、Current command（飞控当前保存并持续发送的 FCS 指令），下方是控制按钮。

设备连接独占一行，FCS 系统状态和 DCDC 输出电流并列。其下两列显示电堆温度、风扇占空比、进气压力、电堆电压和电流、DCDC 状态与故障码、DCDC 温度及系统子状态。QGC 从与活动车辆系统号一致、组件号为 191 的盒子接收 `FUEL_CELL_TELEMETRY`（61002），按有效位显示，测量更新超时后使用占位。

左侧功率由 PMU/电池测量值计算，右侧是飞控下发给 FCS 的请求功率，两者来源不同。PMU 回退或采样时刻不同时，左右功率可以不同。
DCDC 输出电流是 FCS 设备遥测，不是 PMU 电流或飞控内部 CAN 控制电流。SOC 和 DCDC 电流显示两位小数；设备未连接、断连或 QGC 遥测过期时显示 `—`，有效的 `0.00 A` 正常显示。

本版界面与支持独立故障复位位的 FCS-4500 V1.4 PX4 配套使用。SOC 和 DCDC 电流继续按 0.01 单位换算。

飞控仍在内部维护并通过 CAN 下发母线电压和电流，但新版 `FUEL_CELL_STATUS` 不再上报这两个字段，因此 QGroundControl 不显示它们。需要核对实际 CAN 控制值时，应使用 PX4 驱动状态或 CAN 抓包。

状态 13 显示为“输出电流受限”并使用橙色文字，不会禁用开关机或 FCS 急停。原始状态 14、15 显示为“未知状态 (14/15)”，不显示角标也不改变控制权限。

常见连接状态：

| 状态 | 含义 |
| --- | --- |
| Waiting for status | 尚未收到本次车辆会话的有效状态 |
| Never connected | 飞控尚未确认 FCS 连接 |
| Connected | FCS 状态有效且设备已连接 |
| Disconnected | 飞控确认 FCS 已断连 |
| Telemetry expired | QGroundControl 的状态遥测已经过期，不能判断设备当前状态 |

## 6. FCS 操作

右侧提供四个按钮：

- `FCS On`：请求 FCS 开机；
- `FCS Off`：请求 FCS 关机；
- `FCS Fault Reset`：清除 FCS 故障；确认后会将飞控保存的 FCS 指令切换为关机；
- `FCS Emergency Stop`：发送 FCS 协议急停。

操作步骤：

1. 确认右侧状态和控制链路可用。
2. 点击 `FCS On` 后立即发起开机请求，无再次确认；点击 `FCS Off`、`FCS Fault Reset` 或 `FCS Emergency Stop` 时，在确认框中核对目标车辆编号和操作，确认后发送，取消则不发送。复位确认框还会提示当前指令将变为关机。
3. 观察请求结果和 `FCS system status` 的实际进度。

开机仍要求设备已连接、状态遥测新鲜、控制链路可用，且没有待确认的请求。关机、复位或急停确认框打开时，不会同时发起开机请求。开机请求等待确认期间按钮禁用；请求结束后仍可按现有门限再次点击。

复位同样要求设备已连接、遥测新鲜、MAVLink 2 控制链路可用，并等待已有请求结束。飞控确认复位请求后，开机、关机和再次复位暂禁约 400 ms；急停仍可使用。复位受理只表示飞控已开始发送三个控制周期的复位脉冲，不证明故障已经清除。请观察 `FCS system status` 的后续反馈；地面站不会自动重新开机。

“飞控已接受”只表示飞控保存了指令，不表示 FCS 已完成动作。最终执行进度应以设备反馈的 FCS 状态为准。请求超时或链路中断时，界面可能显示结果未知；这不等于设备一定没有执行。

FCS 急停只发送燃料电池协议指令，不会自动锁定飞控、终止飞行或停止飞行器电机。普通请求等待确认期间，急停仍可能按后端门限抢占。

## 7. 不可操作或异常状态

- 飞控整体失联时，旧电池数值改为占位，图标使用中性色，参数编辑禁用。
- FCS 遥测不新鲜、设备未连接或控制链路不可用时，相应按钮禁用并显示原因。
- 参数尚未就绪只影响左侧配置区，不应阻塞电池状态和 FCS 状态。
- 关闭或重新打开详情页、调整窗口、恢复通信都不会自动发送 FCS 指令。
- 没有电池数据时入口仍可显示，以便查看 FCS；没有活动车辆时入口隐藏。

如果入口未显示或页面无法加载，应先确认实际运行的 QGroundControl 构建版本、活动车辆状态和启动日志。不要仅通过修改电池参数来尝试恢复入口。

## 8. 当前限制

- 只使用活动车辆的第一个电池条目，不做多电池聚合或节点选择。
- 不新增 PMU 报文级超时；飞控仍在线但 PMU 停止更新时，电池缓存值可能暂时保留。
- 不显示专用 PMU 回退标志。
- 固定双栏不适配不足以容纳两栏的窗口。
- 真实参数写入、FCS 启停和急停应按项目台架流程验证，不能用软件构建或离屏检查代替。
